Documentación de la API REST - Supabase

Autenticación

Todos los endpoints requieren la siguiente autentificacion: Auth Type: API KEY

{
  "Key": "apikey",
  "Value": "API KEY DE TU PROYECTO",
  "Position": "Headers"
}

El Key lo obtienes desde Supabase en tu proyecto > Settings > API Keys.

GET - formlluviaaguilar - Obtener todos

GET https://supabase.com/dashboard/project/iwdierxmgildaqzycppj/editor/18470/rest/v1/formlluviaaguilar

Devuelve todos los registros de la tabla formlluviaaguilar.

GET - formlluviaaguilar - Filtrar por campos

GET https://supabase.com/dashboard/project/iwdierxmgildaqzycppj/editor/18470/rest/v1/formlluviaaguilar?campo=eq.valor&campo2=eq.valor2

Filtra los registros donde campo sea igual a <valor>.

Campos disponibles para filtrar:

  • id
  • name
  • age
  • email
  • subject
  • message

POST - formlluviaaguilar - Crear nuevo

POST https://supabase.com/dashboard/project/iwdierxmgildaqzycppj/editor/18470/rest/v1/formlluviaaguilar

Crea un nuevo registro. Campos disponibles:

  • name - opcional
  • age - opcional
  • email - (obligatorio)
  • subject - (obligatorio)
  • message - (obligatorio)

Body de ejemplo:

{
  "name": "",
  "age": "",
  "email": "",
  "subject": "",
  "message": ""
}

PATCH - formlluviaaguilar - Editar

PATCH https://supabase.com/dashboard/project/iwdierxmgildaqzycppj/editor/18470/rest/v1/formlluviaaguilar?id=eq.<id>

Actualiza el registro con el ID especificado. Puedes enviar uno o varios campos en el body:

{
  "name": "",
  "age": "",
  "email": "",
  "subject": "",
  "message": ""
}

DELETE - formlluviaaguilar - Eliminar

DELETE https://supabase.com/dashboard/project/iwdierxmgildaqzycppj/editor/18470/rest/v1/formlluviaaguilar?id=eq.<id>

Elimina el registro con el ID especificado.
