Projects

Web Page – Web Vida Verde

Test Leads / QA Team: Team 1 (Lluvia, Ana, Carmen, Cristina)

Testing Scope

The verification process focused on ensuring the correct functionality and usability of the website across different environments. Testing covered both desktop and mobile versions:

  • Desktop Environments: Compatibility and rendering tests across Chrome, Firefox, and Opera browsers.
  • Mobile Environments: Responsive design and user flow testing on Android devices.
  • Validated Key Features: Homepage, catalog navigation and filters, informational sections ("About Us"), shopping cart management, and the complete checkout flow.

Methodology and Tools

Work was conducted under the Agile (Scrum) framework, executing test cycles within each Sprint as new user stories were integrated. The technology ecosystem utilized included:

  • Project Management & Kanban Board: Jira, enabling tracking of the lifecycle for every task and issue.
  • Test Management & Execution: AssertThat, used to structure test cases and ensure comprehensive test coverage.
  • Documentation & Test Plans: Confluence, serving as the centralized repository for strategy and technical analysis.

Executed Testing Types

  • Functional Testing: Rigorous validation of the acceptance criteria specified in each user story.
  • Regression Testing: Execution of test suites after each deployment to guarantee that new features did not negatively impact existing functionalities.
  • Exploratory Testing: Free navigation sessions aimed at detecting anomalous behaviors or unexpected bugs outside established test scripts.
